# GitHub profile / Профиль GitHub

This repository renders the public profile at https://github.com/Shugar86.

- Keep `README.md` and `README.ru.md` equivalent in meaning; English is the profile landing page, Russian is one click away.
- Feature Vids Studio and the selected public projects with concrete descriptions. Verify project visibility and current README before adding or changing claims.
- Never publish private repository names, account-only email addresses, credentials or deployment details here.
- Distinguish products, prototypes, R&D and documentation. A successful CI run does not establish live product acceptance.
- Avoid fixed project/star counts and third-party statistics widgets that become stale or break.
- Keep visual assets local, static and accessible; no scripts or remote fonts inside SVGs.
- For a content/design change, check links, RU/EN parity, image rendering and narrow-screen readability. A test framework is unnecessary for this static profile.
- Review the diff and create a focused commit. Publish only when the user has authorized updating this GitHub profile.
