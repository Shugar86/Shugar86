## 📐 How I work

- **KISS** — the simplest thing that works.
- **Minimal diff** — fix the bug, touch only the bug.
- **Shipping is part of the work** — the result always gets committed.
- **Vibe first** — a product should *feel* right before it scales.
- **No secrets in git** — `.env.example` in the repo, real `.env` and tokens stay local.

## 📐 Принципы работы

- **KISS** — самое простое решение, которое работает.
- **Минимальный diff** — чинишь баг, трогаешь только баг.
- **Commit — часть работы** — результат задачи всегда закоммичен.
- **Вайб первым делом** — продукт должен ощущаться, прежде чем масштабироваться.
- **Никаких секретов в git** — `.env.example` в репозитории, `.env` и токены — только локально.
