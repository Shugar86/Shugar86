## In focus: Vids Studio

### [Make videos in Google Vids with Codex or Claude Code](https://github.com/Shugar86/vids-studio)

Describe the audience, story and materials. The agent works in the Vids document you explicitly connect; the video stays editable in its original editor.

**Creative skills + local MCP connector + Chrome extensions.** Separate packages for Codex and Claude Code, with setup guides in English and Russian.

**Windows · macOS · Linux** &nbsp; | &nbsp; **MIT** &nbsp; | &nbsp; **v0.3.0 preview**

## How I work

**Start with the experience.** What should a person be able to do, understand or feel?

**Build with an AI partner.** Make the intent explicit, keep room for judgment, and review the result.

**Finish the useful part.** Prefer a working, checked change with clear documentation and honest limits.

My tools include **Python, TypeScript, React, Next.js, FastAPI, Node.js, Bun, PostgreSQL, Docker and Linux**.
